## Preferred terms

Use these when they are accurate. They signal that the writer understands how a business actually runs.

| Term | Use it for |
| --- | --- |
| capital allocation | decisions on where cash goes: reinvestment, M&A, buybacks, dividends, debt paydown |
| operating discipline | cost control and execution rigour, especially in a downturn |
| unit economics | revenue and cost per customer, order, seat or unit |
| payback period | time to recover an investment or customer-acquisition cost |
| operating leverage | how profit grows faster than revenue once fixed costs are covered |
| pricing power | ability to raise prices without losing volume |
| switching costs | what it costs a customer to leave |
| gross margin / operating margin | profitability at the relevant level — name which one |
| working capital | cash tied up in inventory and receivables |
| capex / opex | capital versus operating spend — keep them distinct |
| execution risk | the chance that a sound plan is delivered badly |
| concentration risk | dependence on a few customers, suppliers, markets or people |
| regulatory exposure | where rules can change the economics |
| distribution | how the product reaches the buyer, and who controls that path |
| moat | a durable advantage that competitors cannot copy cheaply — always say what it is made of |
| second-order effect | the consequence of the consequence |
| trade-off | what is given up to get something — always name both sides |

## Discouraged terms and plain alternatives

| Avoid | Say instead |
| --- | --- |
| leverage (as a verb) | use, apply, build on |
| utilise | use |
| synergies | cost savings, cross-selling revenue — name and size them |
| ecosystem (as filler) | partners, suppliers, customers, developers — name who |
| solution | product, service, system, tool |
| disrupt / disruption | undercut, replace, take share from — say how |
| transformative / transformational | describe what actually changes |
| world-class / best-in-class | say what the benchmark is |
| robust | strong, resilient, tested — or cut it |
| holistic | complete, end-to-end — or cut it |
| impactful | describe the effect |
| stakeholders (as filler) | shareholders, employees, regulators, customers — name them |
| going forward | from now, next year, over the next two quarters |
| space (as in "the AI space") | market, sector, industry |
| learnings | lessons |
| ask (as a noun) | request |
| key (as a universal intensifier) | important, decisive — or cut it |
| very, really, extremely | cut, or replace with a number |
| myriad | many — or give the count |
| a plethora of | many — or give the count |

## Numbers and hedges

- Prefer "about", "roughly" or "nearly" to stacked hedges ("could potentially perhaps").
- "Doubled", "halved", "a third" are good when the source supports them exactly.
- Distinguish "announced", "committed", "spent" and "booked". They are not interchangeable.
